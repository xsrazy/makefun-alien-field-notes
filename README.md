One original line: a review of planet Earth left by an alien tourist, written for make.fun's "Alien Field Notes: The Two Day Earth Review" bounty. `main.ts` writes exactly that line — at most 200 characters of plain text, no trailing newline — to `entry.txt` in the output directory.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```
